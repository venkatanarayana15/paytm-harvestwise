# Demo Audio Assets

## Record Tamil Command (20-30 seconds)

**Script (for crew recording):**

> "நாளை மழை இருபது சதவீதமும் இருக்கும். நாளைய 20 கிலோ தக்காளி, 10 கொத்து கொத்தமல்லி வேணும்"

**Translation:** "Tomorrow 20% rain. Tomorrow 20kg tomato, 10 bunches coriander."

**Requirements:**
- Save as `command_ta.wav`
- Format: 16kHz mono WAV
- Place in this folder (`ui/assets/`)
- Fallback: typed transcript works if audio missing

**Alternative (shorter):**
> "நாளைய 20 கிலோ தக்காளி"

This triggers the tomato-only flow with engine-fill for coriander.
